# HỌC VĂN CÙNG AI – Giai đoạn 10

Website tự luyện Ngữ văn THCS theo nguyên tắc: **Tự suy nghĩ → AI hỗ trợ → Kiểm chứng → Tự quyết định**.

## Chạy trên máy
1. Cài Node.js 18+.
2. Chạy `npm install`.
3. Tạo file `.env` từ `.env.example`.
4. Điền `GEMINI_API_KEY` trong `.env`.
5. Chạy `npm start`.
6. Mở `http://localhost:3000`.
7. Kiểm tra máy chủ tại `/api/health`.

## Triển khai Render
- Build Command: `npm install`
- Start Command: `npm start`
- Environment: `GEMINI_API_KEY` (bắt buộc), `GEMINI_MODEL` (tùy chọn).
- Không đưa API key vào GitHub hay `public/index.html`.

## Nguyên tắc sư phạm
- 3 phòng: Đọc hiểu, Tiếng Việt, Luyện viết.
- 8 bước: Nhập đề → Tự làm → AI chỉ lỗi → AI gợi ý → Tự sửa → AI chấm → Kiểm chứng → Tự quyết định.
- Cô Mai – Cố vấn Online chỉ phản hồi sau khi học sinh đã tự làm, nhận gợi ý, tự sửa và được AI chấm.
- Bước 7 yêu cầu học sinh tự chọn nguồn, ghi bằng chứng và tự kết luận; AI không tự kiểm chứng AI.
- Kho học liệu chỉ lập chỉ mục SGK Ngữ văn 6–9, Kết nối tri thức; không công khai toàn văn sách.
- Điểm AI là phản hồi luyện tập, không thay thế đánh giá chính thức của giáo viên.
